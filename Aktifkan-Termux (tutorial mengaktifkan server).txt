=====================================================
    PANDUAN MEMBANGKITKAN SERVER ANIME DI TERMUX
=====================================================

Jika Termux terhapus / di-install ulang, lakukan langkah 
ini secara berurutan:

-----------------------------------------------------
STEP 1: Update Termux & Install Node.js
-----------------------------------------------------
Copas perintah ini ke Termux:

pkg update && pkg upgrade -y
pkg install nodejs -y


-----------------------------------------------------
STEP 2: Izinkan Akses File HP
-----------------------------------------------------
Copas perintah ini, lalu klik "ALLOW / IZINKAN" di HP:

termux-setup-storage


-----------------------------------------------------
STEP 3: Masuk ke Folder Project
-----------------------------------------------------
Masuk ke folder tempat simpan file web nya:

cd /storage/1559-A7FB/AnimeApp

-----------------------------------------------------
STEP 4: Install Ulang Library Express
-----------------------------------------------------
Copas perintah ini di dalam folder project:

npm install express


-----------------------------------------------------
STEP 5: Jalankan Server!
-----------------------------------------------------
Nyalakan server:

node server.js


-----------------------------------------------------
NOTE / INFO TAMBAHAN:
- Web bisa diakses di browser: http://localhost:8080
- Untuk mematikan server: Tekan CTRL + C di keyboard Termux
